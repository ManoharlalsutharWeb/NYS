About the Ephemeris

GURUJI uses Swiss Ephemeris with Lahiri ayanamsa — the same ayanamsa used by Drik Panchang and most Indian Vedic astrology software.

The ephemeris data files cover 1800–2399 CE. They are loaded from frontend/ephemeris/ at runtime — no external API calls are made.

Each calculation verifies that the source field equals "swiss". If Moshier (built-in fallback) is used, the calculation is rejected.
